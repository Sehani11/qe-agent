Using these in the paper

Each figure is a standalone <svg> element and can be lifted directly from this page’s source for a LaTeX or Word workflow. Colours are supplied through CSS custom properties so the figures follow the light or dark theme; for a print figure, replace var(--ink), var(--line-2), var(--accent) and var(--muted) with literal values before exporting.
