7. **And** a `.env.local.example` with `NEXT_PUBLIC_API_URL` and Supabase anon key placeholders exists
8. **And** `npm run dev` starts the Next.js dev server on port 3000 without errors

## Dev Agent Guardrails

### Technical Requirements

- **Tooling:** Next.js 15+ (App Router), React 19, TypeScript, Tailwind CSS v3+.
- Use `npm` for frontend package management to match the created settings.

### Architecture Compliance

- **Folder Structure:** Must strictly match standard Next.js `src/` app router structure inside `frontend/`. Path aliases must correctly resolve to `src/` via `@/`.
- **Styling Solution:** Tailwind CSS combined with shadcn/ui. Avoid global custom CSS aside from Tailwind configurations.
- **REST Client Foundation:** The foundation package `axios` is strictly required over native `fetch()` per the architecture decisions, due to the need for scalable interceptor patterns in later epics.

### Library / Framework Requirements

- `@tanstack/react-query`: To be used later for `useSession()`, `useBDDGeneration()` hooks. Provide base provider now.
- `shadcn/ui`: Provides accessible baseline components. Do not build custom UI components for generic form inputs or buttons. Use the library setup CLI.

### File Structure Requirements

- Ensure the React components generated by shadcn route into `frontend/src/components/ui/` by setting the paths correctly if prompted during initialization.

### Testing Requirements

- Application should simply compile successfully (`npm run build`).
- `npm run lint` should complete with no critical errors.

## Dev Notes

- This story implements **Pure Scaffolding**. There is no backend connection, database connection, or LLM connection yet. Focus strictly on file tree structure and baseline capabilities.
- The `Dockerfile` serves as a foundation for `docker-compose.yml` which will be handled during the backend scaffold + wiring story (1.2).

### Project Structure Notes

- Alignment with `architecture.md`: Ensures complete `frontend/` folder separation from the future Python `backend/`.
